## Decision

A cancelled order is represented by a sixth lifecycle state, `cancelled` (BQ-009 option 1). BC-001 now lists six states; cancelling is allowed only in `draft` or `placed`, as before. The code vocabulary (the status constants and the check constraint) adds `cancelled` in the slice that builds a cancellation feature, not before: no code writes `cancelled` today, so the code keeps the five states of VS-005 until then. The VS-005 migration `AlignOrderStatusesToBc001` keeps stopping when it finds a `cancelled` row until that feature exists, as decided in OD-007. VS-004 R2 keeps filtering on the five built states; the `cancelled` filter value arrives with the feature.

## Question

`.claude/hooks/guard_bash.py` is a best-effort second layer behind the `deny` list, not a sandbox. Its module docstring lists known gaps (runtime-built commands, commands inside arithmetic spans, some wrapper long options, some git configuration routes, uncommon interpreters). In default mode the permission prompt still applies to anything the hook misses. Non-blocking. Is the residual list an accepted risk?

## Options

1. Accept it with an expiry: an OD with `accepted_risk: true` and `expires`, revisited when Claude Code's sandbox is enabled for the project (recommended).
2. Fix the listed gaps in the guard.

## Answer

Option 1, decided by the tech lead on 2026-11-27. The residual bypass list of the guard is an accepted risk with an expiry, recorded in OD-033.

## Decision

The order amount filter is deferred from VS-004 until the Order entity has a currency column (TQ-004 option 1), consistent with OD-002. No amount filter is built on an undefined unit and no global currency is assumed (BC-005: one currency per order). When a slice adds the currency column, the filter is reconsidered then, as a new scope item.

## Question

On `pull_request`, GitHub runs `.github/workflows/ai-pr-review.yml` from the PR's merge ref, so a same-repo branch can edit the workflow itself and the edited copy runs with repository secrets before anyone reviews it (CODEOWNERS and branch protection only gate the merge). A repository secret `ANTHROPIC_API_KEY` is therefore readable by anyone with push access. Non-blocking: the review job is skipped without the key. Where does the key live?

## Options

1. An environment secret on a protected environment with required reviewers, and `environment: <name>` on the review job (recommended). Not wired in the template because it needs the environment to exist and was not exercised in CI.
2. Keep the repository secret and accept that anyone with push access can read it.

## Decision

The API has no version segment in its routes: feature route groups are `/api/<feature>` (for example `/api/orders`), not `/api/v1/<feature>`. Introducing a version segment later needs a new OD that supersedes this one.

## Context

Decided on 2026-11-20 by the owner, who holds the product owner, tech lead and privacy roles (as in OD-004), as tech lead. This settles finding B4 in `docs/reference/pipeline-trial-findings.md`: the landed code uses `/api/orders`, and the `backend` skill now cites this record.

## Decision

Answers the remainder of register row E10 in `docs/reference/pipeline-trial-findings.md` (no question record exists for it; the answer is recorded here directly). A reviewer does not start a throwaway container by hand (for example a database container to probe a query). To see how code behaves at run time a reviewer either cites the author's run with the evidence form `author-run: <command>, <commit>, <result>` (`_SHARED-PATTERNS.md`, Bash for reviewers) or runs the repository's own test commands, which may start the containers that the test suite itself starts (Testcontainers). Anything else is listed as `unverified: <check>, no author run` and does not block. Public package-source queries by the two audit commands stay allowed (E10, first half). This binds the reviewer agents (`security-engineer`, `quality-guardian`, `regression-detective`, `documentation-reviewer`).

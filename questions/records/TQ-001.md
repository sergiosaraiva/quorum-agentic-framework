EXAMPLE RECORD (invented "Acme Orders" domain).

## Question

BQ-002 requires gap-free invoice numbers. A PostgreSQL sequence can skip values on rollback. How do we allocate numbers safely when several requests issue invoices at the same time?

## Options

1. A counter row per year, incremented with `SELECT ... FOR UPDATE` inside the issuing transaction (recommended: gap-free by construction, serialises only invoice issuance).
2. A database sequence and accept gaps (rejected by BQ-002).
3. An external numbering service (extra moving part, no present need).

## Answer

Decided in OD-014: option 1, a counter row per year with SELECT ... FOR UPDATE. The owner (product owner, tech lead and privacy roles) answered on 2026-11-20.

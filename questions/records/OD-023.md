## Decision

Risk: `.claude/settings.json` allow-lists `Bash(scripts/run-mutation-tests.sh:*)` and `Bash(python3 scripts/coverage_changed.py:*)`, two commands that run scripts which agents may edit. A changed script would then run without a permission prompt. Owner: the owner, as tech lead, accepted this on 2026-11-20. Compensating factor: changes to `scripts/` reach the integration branch only through a reviewed pull request (`scripts/**` is delegated to `code-engineer`, and a human merges), so a script is reviewed before it is trusted by the allow-list. Remove the two entries at once if agents start editing these scripts without that review. The expiry date 2027-03-20 was confirmed by the owner on 2026-11-20. At expiry (2027-03-20): re-decide with a new OD, or remove the entries and close this record.

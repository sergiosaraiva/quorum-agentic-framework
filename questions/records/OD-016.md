EXAMPLE RECORD (invented "Acme Orders" domain).

## Decision

List and search endpoints bind query parameters that can be malformed as `string?` and parse them explicitly, returning `Results.ValidationProblem` keyed by parameter name (TQ-005 option 1, extended). This applies to `page` and `pageSize` of the VS-001 list as well, not only to the VS-004 filters. In addition, `BadHttpRequestException` is mapped to a 400 response in the exception handler, so Development does not return a 500 for a client error. The follow-up code and tests are tracked in the slice follow-up PR; this record does not claim they are done.

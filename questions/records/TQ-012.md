## Question

`.claude/settings.json` allows `Bash(scripts/run-mutation-tests.sh:*)` and `Bash(python3 scripts/coverage_changed.py:*)` without a prompt. Agents that can edit files under `scripts/` could change either script and then run it without a permission prompt, so an unreviewed change would run inside the session. Is this acceptable, and for how long?

## Options

1. Accept the risk for a limited time (recommended: both scripts are reviewed through the pull request before they reach the integration branch, and removing the entries is a one-line change).
2. Remove both allow-list entries, so each run asks for permission (safe, but every mutation and coverage run prompts).

## Answer

Decided in OD-023: option 1, accepted as a risk with an expiry date. The owner answered on 2026-11-20. The expiry date 2027-03-20 in OD-023 was set by the curator as a default of about four months; the owner may change it.

EXAMPLE RECORD (invented "Acme Orders" domain).

## Question

Is an order's customer name personal data (it may name a natural person)? If yes, may it appear in URL query strings and so in proxy, database slow-query and telemetry logs?

## Options

1. Treat it as personal data; keep GET for R1 only with recorded redaction requirements for proxy logs, OTel url.query and database log settings (recommended: no contract change, the exposure is bounded by configuration).
2. Treat it as personal data and move the search to a POST body (contract change, keeps it out of URLs).
3. Not personal data in this product (no restriction).

## Answer

Decided in OD-012: option 1, customer name treated as personal data, GET kept, redaction requirements recorded. The owner (product owner, tech lead and privacy roles) answered on 2026-11-20.

EXAMPLE RECORD (invented "Acme Orders" domain).

## Question

The landed list endpoint returns every order to any authenticated caller. BC-001 speaks of 'a customer' but no chunk says whether a user sees only their own orders, or all orders (staff). Does search inherit that, or must results be restricted per caller?

## Options

1. Same visibility as the VS-001 list: any authenticated caller sees all orders (recommended for this slice only if the owner confirms VS-001 is correct; adds nothing new).
2. Restrict results to orders owned by the caller (needs an owner column and a role model: new data and auth work).
3. Role-dependent: staff see all, customers see their own.

## History

- 2026-11-19: raised by requirements-analyst during the VS-004 readiness analysis. Does not block the design. Design assumes option 1 and flags it for security-engineer; a different answer changes data model and auth.
- 2026-11-19: security-engineer round 1 review of VS-004 R1: any authenticated principal can search every customer's orders. Severity is Low under the working assumption (option 1) but becomes Critical if this question is answered 'restricted' (option 2 or 3). It must be answered before R1 reaches any environment where non-staff identities can obtain a token for the audience; until then consider a named authorization policy instead of bare `RequireAuthorization()`. Priority raised from P2 to P1 in the frontmatter because of that deadline.

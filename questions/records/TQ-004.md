EXAMPLE RECORD (invented "Acme Orders" domain).

## Question

BC-005 says an order has exactly one currency (ISO 4217 code stored with amounts). The landed Order entity has TotalAmount but no currency column. If BQ-003 allows an amount-range filter, which currency applies to the bounds, and when does the currency column land?

## Options

1. Defer the amount filter from VS-004 until the currency column exists (recommended: avoids a filter whose unit is undefined).
2. Add the currency column in a VS-001 follow-up, then filter on amount plus an optional currency parameter.
3. Assume one global currency (rejected: contradicts BC-005).

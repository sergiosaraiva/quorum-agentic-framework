## Decision

An order's customer name is treated as personal data. The customer-name search stays a GET for R1 only, with recorded redaction requirements (BQ-008 option 1); moving it to a POST body (option 2) is not chosen. The redaction requirements cover three log surfaces: proxy logs, the telemetry `url.query` attribute and database log settings. Curator wording, owner to confirm: the customer-name value should not appear in any of the three. How this is met depends on the deployment target (not recorded) and on the telemetry setup; it is follow-up work, and this record does not claim it is done. What applies after R1 is not decided here: if the search is extended beyond R1, a later question must decide whether GET remains acceptable.

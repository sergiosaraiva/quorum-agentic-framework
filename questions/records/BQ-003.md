EXAMPLE RECORD (invented "Acme Orders" domain).

## Question

VS-004 adds search and filters to the order list. BC-001 and BC-005 define order states, totals and currency, but no chunk says which of them a user may filter by. Which filters does the first release offer?

## Options

1. Status (exact match, one value), created-date range (from/to) and customer name; no amount filter (recommended: smallest set that matches how BC-001 describes an order; amount needs a currency rule, see TQ-004).
2. Option 1 plus a total-amount range.
3. Status only.

## Answer

Filterable fields in the first release: status, created-date range, customer name. No total-amount filter (option 1; the amount filter stays deferred, see TQ-004). Answered by the product owner on 2026-11-19. Recorded as OD-002.

## History

- 2026-11-19: raised by requirements-analyst during the VS-004 readiness analysis. Blocks the filter parameters of the VS-004 R2 contract. Meanwhile the design proceeds on the shared parts: query shape, paging, auth, validation and empty results.
- 2026-11-19: answered by the product owner; decision recorded as OD-002. VS-004 filter parameters can be fixed.

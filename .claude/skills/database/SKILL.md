# Creating EF Core Entities

Design Principles: `.claude/agents/_SHARED-PATTERNS.md`. A data-model conventions doc, if the project keeps one (for example `docs/datamodel/CONVENTIONS.md`, adopter-supplied, not shipped), is authoritative; this skill shows how to express it in EF Core.

## Quick Reference

- Entities are plain POCOs (no EF attributes) in `src/Infrastructure/Persistence/Entities/<Schema>/`; mapping lives in `IEntityTypeConfiguration<T>` under `Persistence/Configurations/<Schema>/`
- `UseSnakeCaseNamingConvention()` at every `DbContextOptions` build site: `src/Api/Program.cs`, `src/Infrastructure/Persistence/AppDbContextFactory.cs` and any test or CLI that builds its own options (no shared helper exists). They must agree, or `Migrate` throws "pending model changes". Never hand-roll casing
- Tables are singular and named explicitly with `ToTable("<singular>")`. Schema-qualify (`ToTable("<singular>", "<schema>")`) when the product has more than one schema (`src/Infrastructure/CLAUDE.md`); a single-schema product stays in `public` (landed: `ToTable("order")`). With schemas, pin the EF migrations-history table to its own schema
- Primary key `id uuid`, app-generated with `Guid.CreateVersion7()`. A very high-volume fact table may use `bigint GENERATED BY DEFAULT AS IDENTITY`
- FKs are `<referenced_table>_id`; a natural-key text code is `<referenced_table>_code`
- Names over 63 bytes get a hand-picked name (`HasConstraintName`, `HasDatabaseName`). Index only what a real query needs; dropping `ForeignKeyIndexConvention` removes FK indexes
- Money, rates and quantities: `numeric(p,s)` via `HasPrecision`; the adopter's decision sets p,s (Acme example, OD-001: `numeric(18,2)` amounts + `char(3)` currency, landed `HasPrecision(18, 2)`). Never `float`, `double` or `money`
- Timestamps are `timestamptz` (`DateTimeOffset`); dates without time are `date` (`DateOnly`)
- Closed code-owned enum: text column + a `CHECK` built from one vocabulary source (landed, OD-004: lowercase constants `OrderStatuses`, `CHECK` from `OrderStatuses.All`). A C# enum needs a string converter you define yourself. Data-owned or extensible set: a lookup table with a natural `code` key. No native PostgreSQL enums (values cannot be dropped)
- Audit columns: `created_at`, `updated_at` on every entity, set from `TimeProvider` in the service (landed: `OrdersService.CreateAsync`). When `created_by`/`updated_by` are required, use a `SaveChanges` interceptor so callers never set them. Map `xmin` as the concurrency token (`.IsRowVersion()`)
- No blanket soft delete. Where required: `deleted_at` / `deleted_by`, a partial unique index `WHERE deleted_at IS NULL`, a named EF query filter, never `is_deleted boolean`
- Period-valid data: `daterange valid_during` + `EXCLUDE USING gist` (`btree_gist`), end-dated, not updated in place
- `DeleteBehavior` per relationship: `Cascade` only when the child is meaningless without the parent, else `Restrict`/`SetNull`
- Per-customer settings: one typed single-row `<area>_setting` table, not key/value. Deploy-varying values stay in Options (`creating-configuration-options`)

## Multi-tenancy (optional, decide once)

| Model | Rule |
|-------|------|
| Database per tenant | No `tenant_id` column, no tenant query filter. Isolation is the connection string, resolved once per DI scope by an `ITenantConnectionResolver` from the validated token claim, never from request input. Background work takes the tenant from the message envelope only, one scope per message. Fail closed |
| Shared database | `tenant_id` on every tenant table, a global query filter, tenant-leading indexes, and a test that proves cross-tenant reads return nothing |
| Single tenant | Neither. Do not add either speculatively |

Cached tenant data: tenant-prefixed key (`implementing-caching-strategies`); logs: tenant in a logger scope (`implementing-observability`).

## Example

```csharp
// OrderStatuses: const strings plus `All`, the one vocabulary source
public sealed class Order
{
    public const int CustomerNameMaxLength = 200;      // shared by configuration, DTO and validator
    public Guid Id { get; set; }                       // uuid v7, app-generated
    public required string CustomerName { get; set; }
    public required string Status { get; set; }
    public decimal TotalAmount { get; set; }
    public DateTimeOffset CreatedAt { get; set; }      // CreatedAt, UpdatedAt: set by the service from TimeProvider
    public DateTimeOffset UpdatedAt { get; set; }
}

public sealed class OrderConfiguration : IEntityTypeConfiguration<Order>
{
    public void Configure(EntityTypeBuilder<Order> builder)
    {
        builder.ToTable("order", t => t.HasCheckConstraint("ck_order_status",
            $"status in ({string.Join(",", OrderStatuses.All.Select(s => $"'{s}'"))})"));   // 2nd arg: schema, when several
        builder.HasKey(o => o.Id);
        builder.Property(o => o.Id).ValueGeneratedNever();
        builder.Property(o => o.CustomerName).HasMaxLength(Order.CustomerNameMaxLength).IsRequired();
        builder.Property(o => o.Status).HasMaxLength(20).IsRequired();
        builder.Property(o => o.TotalAmount).HasPrecision(18, 2);
    }
}
```

Interceptor (when `*_by` is required): a `SaveChangesInterceptor` walks `ChangeTracker.Entries<IAudited>()` and stamps `Created*` on `Added`, `Updated*` on `Modified` from `TimeProvider` and the current principal.

## Quality Checklist

- [ ] snake_case, singular, explicit `ToTable`, schema-qualified when several schemas; UUIDv7 key; `HasPrecision` on every decimal
- [ ] Enum is text + `CHECK` from one vocabulary source, or a lookup table; no native enum
- [ ] Audit columns set by one mechanism (service from `TimeProvider`, or interceptor when `*_by`); `xmin` concurrency token on mutable aggregates
- [ ] Every index names a real query; no speculative columns or generic `jsonb` blobs
- [ ] Delete behaviour chosen per relationship; soft delete only when required
- [ ] Tenant model decided and applied consistently

## Common Mistakes

| Wrong | Correct |
|-------|---------|
| `float`/`double` for money | `numeric` with `HasPrecision` |
| `Guid.NewGuid()` keys | `Guid.CreateVersion7()` |
| Audit stamping scattered across callers | One place: the service (landed) or an interceptor when `*_by` is required |
| `is_deleted boolean` | `deleted_at` + partial unique index |
| `CREATE TYPE ... AS ENUM` | `text` + `CHECK`, or a lookup table |
| Several bounded contexts in one schema | One schema per bounded context |

## Decision

Risk, as a class: any allow-listed build or test command in `.claude/settings.json` runs code that an agent can edit without a prompt. Routes left open:

- `scripts/kb/tests/**`, nested `scripts/kb/**` subdirectories and `scripts/tests/**`, run by `python3 -m unittest`.
- Test code under `tests/**`, run by `dotnet test`.
- `frontend/package.json` scripts and the vitest and playwright configs, run by `npm run build`, `npm run test`, `npx ng test` and `npx playwright test`.
- MSBuild switch spellings that the `ask` globs miss.
- MSBuild accepting any file name as a project (`dotnet build src/x.xml`), which extension globs cannot cover.

Owner: the tech lead accepted this on 2026-11-27 (TQ-020, option 1). Mitigation: the permission prompt for everything else; the PreToolUse Bash guard, which blocks build-event overrides and asks before shell output redirection except to `/dev/null`, fd dups or paths outside the repository (Claude Code checks redirect targets against Edit allow rules but not Edit ask rules, so `git log --format=... > scripts/json.py` wrote files without a prompt); the allow-listed gate scripts (`ai_review_local.py`, `framework_lint.py`, `coverage_changed.py`) and the KB scripts (`check_chunks.py`, `search.py`, `mcp_server.py`), which drop their own directory from `sys.path` (the KB scripts load `lib` and `backends` by path) so a planted `scripts/<stdlib-name>` module cannot shadow the standard library; and the `ask` rules that prompt before `Edit` or `Write` of any top-level `./scripts/*.py`, `./scripts/*/__init__.py`, `./scripts/kb/*.py`, `./**/*.*proj`, `./**/*.props`, `./**/*.targets`, `./**/*.rsp` and `./**/*.user` (full reasoning in TQ-020). Only `Edit(path)` rules are matched by Claude Code's file checks; the `Write(path)` twins are kept but inert. The `./scripts/*.py`, `./scripts/*/__init__.py` and `./scripts/kb/*.py` rules gate editing the scripts. Commands that write files themselves (dotnet `-bl:`, `-flp:logfile=`, `--artifacts-path`, `dotnet format`) remain open (OD-033); such a write could even overwrite the guard, and a failing hook fails open. A reviewed pull request protects only the integration branch, not the developer machine. The real boundary is the permission prompt and, once enabled, the Claude Code sandbox. At expiry (2027-05-27), or when the sandbox is enabled (as for OD-033), revisit: gate the remaining routes (for example `ask` rules for `scripts/tests/**` and `scripts/kb/tests/**`, or removing allow entries) or renew with a new OD. Extends OD-023, which covers the mutation and coverage scripts.

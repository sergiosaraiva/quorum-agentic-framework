## Decision

Every environment's database must be created with a UTF-8 `LC_CTYPE` (for example `en_US.utf8`), written into the infrastructure code, and customer-name search keeps `ILIKE` (TQ-006 option 1). No `citext` type or ICU collation is added, and no migration. The requirement is added to the infrastructure guidance in `src/Infrastructure/CLAUDE.md`; the creation parameters in the infrastructure code follow when a deployment target is chosen and are not done by this record.
